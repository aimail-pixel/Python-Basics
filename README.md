# Python-Basics

Standalone Python examples organized by subject. The examples are taken from
[`doc/Core_Basics.html`](doc/Core_Basics.html): each lesson example and each
complete module program has its own script with a `main()` entry point.

| Folder | Subject |
| --- | --- |
| `GettingStarted/` | Overview, interpreter, setup, and basic programs |
| `Variables/` | Variables, data types, and literals |
| `Operators/` | Operators and expressions |
| `Branching/` | Control flow and decisions |
| `Loops/` | Loops and iteration |
| `Strings/` | Strings and text manipulation |
| `Lists/` | Lists |
| `Arrays/` | The `array` module |
| `TuplesAndSets/` | Tuples and sets |
| `Dictionaries/` | Dictionaries |
| `Functions/` | Functions, scope, and modules |
| `OOP/` | Object-oriented Python |
| `RegularExpressions/` | The `re` module |
| `ExceptionHandling/` | Errors and exception handling |
| `FileHandling/` | Files, CSV, and JSON |
| `DailyUtilities/` | Practical utility programs |

Lesson scripts use the topic name and an example number, for example
`Branching/if_example_01.py`. Complete module programs are named
`*_complete_program.py`. Run any script from the repository root with:

```console
python Branching/if_example_01.py
```
